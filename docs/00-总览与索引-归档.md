## 五、已确认的核心事实（摘要）

- **字体**：`Backup` 属性 `0x810000` = `/usr/share/app/fontlist.dat`；注册不校验文件存在；**放好三个真机字体即不崩溃，零代码改动**。
- **eMMC 停滞**：`emmc.ko` 的调优函数改 `mov r0,#0; bx lr` 根除。
- **显示/GPU**：VPH ch53 640×480 双缓冲；draw kick 实测 100+ 次。
- **按键**：`/proc/udm/input` 可读；**MENU = `0x1AC`，ADC port `0xF`，电平 0–0x5B**。
- **UI 是用户态进程**（PID 144，172 线程，libObj 基址 0x057E3000）。

## 六、已撤回的错误结论

UI 在内核态 ❌ · UI 从不 draw kick ❌ · 字体需调 registerFontFaceFile ❌ · `/var/fifo` 是通道 ❌ · 按键走 evdev ❌ · sdhci 参数可修 eMMC ❌
