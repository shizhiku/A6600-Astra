# 99 · 模拟器交互演示使用说明

本页把原厂固件跑在隔离 QEMU 里，通过浏览器显示实时画面并注入按键。它只读原厂固件副本、只写本次运行目录，不接触真机。

## 打开

在 Windows 浏览器打开：

**http://localhost:8765/**

如果打不开，说明 WSL 里的演示进程没在运行；重新启动见文末。

## 按钮

| 按钮 | 作用 | 已验证 |
|---|---|---|
| `MENU (front bit2)` | 模拟机身 MENU 键 | 会关闭对话框/返回拍摄界面 |
| `ENTER (ADC ch3)` | 模拟 ENTER/确定键 | 会打开/确认菜单对话框 |
| 选择器 ch4/ch5 各 5 档 | 模拟多选择器 ADC 电平，用于探索方向键 | 通道与电平的对应关系**未验证**，可逐个试 |

页面每 0.7 秒刷新一次实时画面；每次刷新会请求 QEMU 导出当前帧。

## 已验证的操作序列

1. 开机停在“运行于NTSC。”提示（蓝色背景）。
2. 点 **ENTER** → 出现对话框：“该操作或设定无法如下进行。”，选项“照相模式 / 程序自动”，右下角“确定”。
3. 点 **MENU** → 回到拍摄界面：`P`、`NO CARD`、电量 42%、中央对焦框。

## 边界

- 这是**四代原厂固件**的交互演示，不是五代 ASTRA UI。ASTRA 镜像目前停在应用侧 `notify_model_system_error` 断言，尚无可用界面。
- 按键注入是模型级模拟（front bit2 / ADC 通道电平），不是真实按键扫描；部分组合可能不响应或被固件忽略。
- 演示进程与 QEMU 都是本次会话的临时产物，重启后需重新启动。

## 重新启动

```bash
wsl -d Ubuntu --exec python3 "<WORKSPACE>/02-脚本/98_interactive_demo.py" --port 8765
```

脚本会新建 `/root/astra/interactive/<时间戳>/` 运行目录，写入串口日志、stderr 和实时帧 `live.ppm`。QEMU 参数与已验证的无头运行一致（`sony-a6400,rear-controls=on,submicro-frames=...`）。
