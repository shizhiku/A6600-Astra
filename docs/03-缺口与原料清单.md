# 03 · 缺口与原料清单

## 1. 唯一缺的东西：五代 UI 的 5 个库 + 232 个资源

| 文件 | 大小 | 从哪来 |
|---|---|---|
| `lib/appFw.so` | 64,273,528 B | ZV-1M2 `/usr` |
| `lib/libObj.so`（五代，改名 `libOb5.so`） | 3,931,624 B | ZV-1M2 `/usr` |
| `lib/libmpr.so`（五代，改名 `libmp5.so`） | 3,038,540 B | ZV-1M2 `/usr` |
| `lib/AdjChkConfig.so` | 82,440 B | ZV-1M2 `/usr` |
| `lib/appFwBoot.so` | 8,312 B | ZV-1M2 `/usr` |
| `share/app/` | 232 个文件 | ZV-1M2 `/usr` |

> 以上大小取自 ZVE10-Astra 的 `prod_image_manifest.json`，是移植后注入镜像的尺寸。

---

## 2. 为什么从官方固件拿不到

| 事实 | 证据 |
|---|---|
| ZV-1M2 从 1.01（2023-10-31）起就是 **SD 卡更新**（`BODYDATA.DAT`），**从来没有 Windows `.exe`** | 索尼各地区支持页 |
| 包内**不含**装着更新器的 `nflasha1` | CST 研究文档 |
| 解密/验签在**相机端**（`appFw.so` 识别阶段 + `nflasha1` 执行阶段） | 同上 |
| 官方包用**未公开的容器密钥**加密 | 本方案 02 §10 实测：4 个公开密钥全部失败 |

**所以：官方包既不含密钥，也不含能解自己的东西。**

---

## 3. 三条获取路径

### 路径 A：一台 ZV-1M2（最干净，但最难）

- 目标：从其 `/usr`（nflasha15）取出 5 个库 + `share/app`
- 难点：ZV-1M2 是 **CXD90057** 平台，`/etc` 在只读 rootfs 上；CST 研究结论是
  「服务模式机制存在，**入口待打通**」——社区目前**还没有**打通 ZV-1M2 的服务通道
- 可行性：**低**（相当于先复现别人都没做成的事）

### 路径 B：向作者要（最高效）

- 对象：`nolan2628`（ZVE10-Astra 作者）、`cokeenet`（ZV-E10 研究）
- 要什么：**那 32 字节的容器密钥**，或者直接给 ZV-1M2 的解包目录
- 为什么可能给：密钥是"格式事实"，不涉及分发索尼二进制；但库本身受版权约束，对方未必愿意
- 可行性：**中**（取决于对方意愿）

### 路径 C：等社区

- 一旦有人打通 ZV-1M2 的通道或公开密钥，这条路立刻通
- 可行性：不可控

---

## 4. 需要向对方说明的技术请求（精确版）

如果对方愿意帮忙，最小请求是：

```
1) ZV-1M2 的容器密钥（32 字节），或
2) ZV-1M2 官方固件解包后的 /usr 目录，至少包含：
   lib/appFw.so
   lib/libObj.so
   lib/libmpr.so
   lib/AdjChkConfig.so
   lib/appFwBoot.so
   share/app/（232 个文件）
```

以及（可选，能省很多时间）：

```
3) 他们用的 ZV-1M2 固件版本号
4) libIMDB 模块表的改写脚本或说明（a6600 的表是 33,924 B，与 ZV-E10 的 37,044 B 不同）
```

---

## 5. 为什么这一步不能"绕过"

UI 的一切都建立在那 64 MB 的 `appFw.so` 上：

- 没有它，S2 的符号冲突扫描没有对象
- 没有它，S3 的引导垫片没有东西可加载
- 没有它，S4 的触控/EVF/IBIS 桥接没有调用方

**它不是"可选的参考实现"，它就是 UI 本身。**

---

## 6. 备选：不移植 UI 也能做的事

如果 S1 长期无解，a6600 上仍然可以做**不使用五代库**的改造：

| 项目 | 依赖 | 风险 |
|---|---|---|
| 1080p → 1920×1280 开放门（anlock6600 方案） | 只改 a6600 自己的 `libmpr.so` 一个字节 | 低 |
| 去掉录影时长/地区限制 | 改 a6600 自己的库 | 中 |
| 预置自定义脚本 / 改 UI 文字 | 改 `/usr` 或 `0800_appli` | 中 |
| 自制完整固件并刷入 | S0 已具备 | 高（无救砖路径） |

这些都能用 **S0 已经打通的固件链路** 实现，不需要 ZV-1M2。
