# 实验产物：禁止作为可刷固件使用

当前目录中的 `nflasha15_astra.dat`、`nflasha15_patched.bin` 和最小引导垫片均属于离线研究产物。未通过 UI 启动或真机适配验证。

2026-11-20 复核确认：

- DAT 解密回读成功只证明容器层能够解析，不证明设备接受修改后的包，也不证明启动安全。
- `firmware_patched.tar` 中 `0701_part_image_sum/part_image.sum` 的 nflasha15 校验值仍为原厂的 `520fff36`，修改后分区实际 CRC32 为 `129576f8`，不一致。
- 256 字节 trailer 被原样复制，其在目标设备上的验证机制尚未确证。
- 所谓闭包检查仅按文件名检查 DT_NEEDED；没有验证搜索路径、符号版本、重定位、所有导入符号或运行时 ABI。
- 当前镜像仍是四代 UI 加最小转发垫片，不包含完整 ASTRA UI 移植。
- QEMU 输入中的 Backup.bin 是合成 fixture，不是相机设置备份。启动失败不能直接归因于补丁，必须与原厂镜像对照。

当前没有可刷、已验证正常启动的 a6600 ASTRA 固件。此说明取代此前关于“完整可用包”“四重验证即完成”的表述。
