# 05 · 工具说明

`tools/` 下的脚本全部是**离线**工具（除 `probe/` 里的探测脚本会连接相机）。

---

## 一、固件解包（离线，不需要相机）

### `decode_updater.py`
把官方 `Update_ILCE6600V110.exe` 解成 tar + 分区镜像。

```bash
python decode_updater.py "<HOME>\Downloads\Update_ILCE6600V110.exe"
```

产出（`a6600_fw/`）：

```
fdat_plain.bin       315,434,496 B   FDAT 明文
firmware.tar         315,290,624 B   175 项
updater.img              143,360 B
extracted/0700_part_image/dev/nflasha{3,5,7,15}
extracted/0300_partconf/partinf.conf
```

依赖：`pycryptodomex`。内部自带 FDAT 解密（`key_cxd90045`）。

### `read_usr.py`
纯 Python 读 ext2（不需要 WSL/debugfs），列出 `/usr` 全部文件并导出关键库。

```bash
python read_usr.py
```

产出：`a6600_fw/usr_filelist.txt` + `a6600_fw/usr/` 下的关键库。

### `analyze_usr.py`
ELF 级检查：`.text` 偏移、hook 特征串、补丁站点。

```bash
python analyze_usr.py
```

输出示例：

```
libAK8975.so  .text @0x988          ← A6400 挂钩工具的 PATCH_ADDR
libmpr.so     @0x87fe08 = 4ff48763  ← anlock6600 的 1080p 补丁站点
libObj.so     A6400 12-byte prologue @0x5f22b0（唯一）
```

## 二、重打包（离线，S0 核心）

### `repack_a6600.py`
把明文重新封装成 DAT，重建容器与 CRC，并与原包逐字节比对。

```bash
python repack_a6600.py
```

期望输出：

```
[+] 密文：逐字节一致 ✅
[*] DEND CRC 原=157D2ED5 新=157D2ED5 一致
[+] DAT：逐字节一致 ✅  (316,672,424 B)
```

这是整个工程的"地基验收"——**只有这一步过，后面改内容才有意义**。

### `decrypt_cst.py` / `validate_framing.py`
用于分析**其他机型**的容器（A6700 / ZV-1M2 等），支持多密钥试探。

```bash
python validate_framing.py     # 同时测 a6600 与 ZV-1M2 的密钥
```

## 三、相机探测（**需要连接相机**）

> 前置：WSL2 + usbipd + PMCA vendored 副本。详见 `04-风险与安全边界.md`。

| 脚本 | 作用 | 是否写入 |
|---|---|---|
| `probe_readonly.py` | 17 条只读命令（`cat`/`ls`/`df`/`ps`） | ❌ |
| `probe_writetest.py` | 建/删一个 1 字节文件验证写权限 | 极小（自删） |
| `set_preload.py` | 写 `dmode`/`preload` | ✅ |
| `install_etc.py` | 写 `/etc/astra_probe.so` + `/etc/ld.so.preload` | ✅ |
| `read_logs.py` | 用文件协议读日志（不经过 shell，最稳） | ❌ |
| `cleanup_preload.py` | 删除 `/etc/ld.so.preload` 等 | 删除 |

**经验**：Senser 的**终端（shell）会话很容易断**，而**文件协议（readFile/writeFile/deleteFile）非常稳**。
所以尽量用文件协议，少用 shell。

## 四、已知的坑（实测踩过）

| 现象 | 原因 | 处理 |
|---|---|---|
| `No devices found` | WSL 的 `usb-storage` 抢占了相机接口 | `echo 1-2:1.0 > /sys/bus/usb/drivers/usb-storage/unbind` |
| `Waiting for camera to switch… timed out` | 切换到 `054C:0336` 需要重新 attach | 再跑一次脚本；或 `usbipd attach --busid <X>` |
| `GenericUsbException` | shell 会话被相机掐断 | 改用文件协议 |
| 相机从 USB 消失 | 省电休眠（默认 1 分钟） | 相机设置 → 节电 → 自动关机 = 30 分钟 |
| `No such device` | usbipd 的 busid 变了（换了 USB 口） | `usbipd list` 重新确认 busid |

## 五、环境依赖

```
Python 3.10+
pycryptodomex        （FDAT 解密/加密）
pyelftools           （ELF 分析）
capstone             （可选，反汇编验证）
```

相机探测额外需要：

```
WSL2 (Ubuntu) + usbipd-win + python3-usb + python3-pycryptodome
PMCA vendored 副本（来自 ZVE10-Astra 仓库 tools/flash/camtool/vendor）
```
