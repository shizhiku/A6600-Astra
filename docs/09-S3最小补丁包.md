## 2. 垫片（`a6600_port/appFwBoot.so`）

```c
int Application_System_Init(void *arg)
{
    void *h = dlopen("libObj.so", RTLD_LAZY | RTLD_GLOBAL);
    init_fn fn = dlsym(h, "Application_System_Init");
    return fn(arg);          /* 行为应当与打补丁前完全一致 */
}
```

编译参数（照搬 ZVE10 的）：

```
zig cc -target arm-linux-gnueabi.2.4 -mcpu=cortex_a9 -mthumb -shared -fPIC -O2 -s
       -Wl,-z,lazy -Wl,-z,norelro -Wl,-z,max-page-size=0x1000
```

| ABI 校验项 | 结果 |
|---|---|
| `e_flags` | `0x05000002` ✅ |
| 导出 | 仅 `Application_System_Init` ✅ |
| 外部依赖 | `dlopen` / `dlsym` ✅ |
| 版本需求 | `GLIBC_2.4`（相机是 2.11.2）✅ |

## 3. 验证结果

**（1）补丁落地**：4 个文件写回 ext2 后逐字节比对 → 全部 MATCH。

**（2）模块表形态**：

```
入口条目 @0x70F8
  psid = 0x00000083            （原厂 0x07FB0083）
  file = 0x4CC9 -> 'appFwBoot.so'
  init = 0x4978 -> 'Application_System_Init'
```

与 ZV-1M2 原厂条目结构完全一致。

**（3）DAT 回读**：用 fwtool 按官方流程解回来：

```
crypter   CXD90045
model     0x81030014  version 1.10
tar       315,299,840 B
nflasha15 215,517,184 B  与补丁镜像逐字节一致 ✅
```

**（4）动态库闭包**：164 个动态库，`DT_NEEDED` 全部能在 `/usr` + rootfs 中找到 ✅
