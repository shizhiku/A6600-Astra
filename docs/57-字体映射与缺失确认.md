# 57 · 字体映射与缺失确认（相机采集受阻）

本轮为离线扫描与两次只读探测尝试。无设备写入。

## 一、字体映射表（更新包与相机完全一致）

`/usr/share/app/fontlist.dat`（360 字节，制表符分隔）：

```
FONT_UNIVERS    /usr/share/app/UniversOTS-SJ_wIcon.ltt          0 0
FONT_JAPANESE   /usr/share/app/HeiseiKakuGothW5-SJ_wIcon.ltt    0 0
FONT_KOREAN     /usr/share/app/MYingHeiC-KSX1001-SJ_wIcon.ltt   0 0
FONT_S_CHINESE  /tmp/images/MYingHeiC-GB18030-SJ_wIcon.ltt      0 0
FONT_T_CHINESE  /tmp/images/MYingHeiC-Big5-SJ_wIcon.ltt         0 0
FONT_ICONS      /usr/share/app/Sony_DI_Icons.ttf                0 0
```

**相机上的同名文件内容与更新包完全一致**（已只读采集比对）。

## 二、更新包的 `/usr` 缺少中文字体本体

`/usr/share/app/` 下实际只有：

```
UniversOTS-SJ_wIcon.ltt          611,416 B
HeiseiKakuGothW5-SJ_wIcon.ltt    851,496 B
MYingHeiC-KSX1001-SJ_wIcon.ltt   924,104 B   （韩文 KSX1001）
```

**没有 `MYingHeiC-GB18030-*` 与 `MYingHeiC-Big5-*`**（即中文简体/繁体字体）。

`nflasha7`、`nflasha5`、initrd 中也都没有这些字体载荷，仅存在路径字符串。

## 三、结论：字体要在运行时落到 `/tmp/images`

- 相机与更新包的 `fontlist.dat` 都指向 **`/tmp/images/`**；
- 但固件里没有对应的 `.ltt` 本体；
- 因此该字体必然由**某个运行期步骤**放入 `/tmp/images`（解包、复制或下载）。

`TextRM_loadFont("FONT_S_CHINESE")` 失败 → `libObj` 上报错误 → `abort()`，正是因为 `/tmp/images` 中没有该字体。
